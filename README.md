# system-activity-monitor
A Python-based system activity monitoring tool that logs user input and sends real-time email alerts using SMTP, designed for cybersecurity and SOC analysis learning.
# 🔐 System Activity Monitoring & Email Alert System

## 📌 Overview

This project monitors system activity (keyboard input) and sends real-time email alerts using Python.

## 🚀 Features

* Keystroke logging
* Email alerts using SMTP
* Multi-threading for continuous monitoring
* Shutdown alert system

## 🛠️ Technologies Used

* Python
* smtplib
* pynput
* threading

## ⚠️ Note

This project is for educational and ethical cybersecurity purposes only.

## ▶️ How to Run

1. Install dependencies:
   pip install pynput

2. Set environment variables:
   EMAIL=your_email@gmail.com
APP_PASSWORD=your_app_password

3. Run:
   python sender.py
